# ADR-WP2A — fake integration seam and independent evidence ledger

Status: implementation proposal for independent review under Issue #14. Base `c3eceecee5d8538f6426ee60ecb93563f14d8805`. ADR01–07 and all safety gates remain binding.

## Boundary and dependency decisions

- Add `packages/offline/` immutable WP2A contracts/envelope2.0, `packages/ha_fake/` in-memory source and orchestration, `packages/evidence/` pure accounting plus separate disposable SQLite, and `packages/migration/` synthetic rehearsal. All accepted WP1A/B/C source and219 tests remain byte-identical. No enabled component, real HA SDK/client, URL/token option, device transport or daemon exists.
- Fake sessions use an in-process issuer seal and current grant epoch; serialized `Principal` data alone has no authority. This is test capability modeling, not real HA authentication. Fake settings save performs trusted STOP before durable I/O, CAS/configure/readback, and a fenced unreconciled fake-runtime restart. A failure cannot return `saved`. Actual state/physical effect remain unknown unless explicitly modeled; fake ACK never verifies equipment.
- Cache the configuration revision/armed premise outside the STOP path. `trusted_stop`/`emergency` never read either SQLite store. Source/pump processing rechecks fresh current inputs even when no command is queued. Evidence drains are explicit worker operations, with no shared evidence lock needed by safety.
- Keep thermostat ownership distinct from fan ownership. Stale/reordered source reports cannot create fresh manual changes. Manual/unknown/unproven self-labelled thermostat echoes pause automatic ownership through the accepted runtime. A manual fan event preserves fan control independently. Existing pure fan hysteresis/arbitration is reused, with no fan sender.

## Data and accounting decisions

- Require explicit synthetic binding handles, physical/source IDs, units, ages, alias priorities and capabilities. Alias policy either explicitly prefers priority or returns unknown for conflicting values/times; never average. Selected group/phase/load footprints and runtime dependency graphs cannot overlap; signed GRID is a separate qualified subtraction, never Deye LOAD/battery/CT duplication. `qualified=True` in a fixture is a premise, not household proof.
- Preserve every admitted raw source fact in a bounded4096-event fake journal. The control queue coalesces ordinary events after128 pending updates and reserves128 ownership events. Overflow fails disconnected/unknown rather than implying a healthy source. Explicit bounded journal pages archive coalesced facts separately; archive pending/lost counts remain visible. This is an isolated replay harness, not production event transport.
- Evidence DB accepts only a fresh `heating-wp2a-*` child of the actual temporary root, fixed filename, no symlink/hardlink redirection, WAL/FULL and qualified linked SQLite. It is separate from the accepted critical DB and cannot be configured with an HA database path. Schema1→2 migration is transactional; unknown/corrupt schema is blocked, never reset. The old schema is a synthetic rehearsal format, not a claimed legacy SQLite importer.
- Journal entries are append-only, strict-envelope/checksum protected and chained by monotonic sequence. Immutable indexes describe origin/energy/forecast rows. Source identities, stream and timestamps are bound to payload; energy origin/frontier/materialization are checked against journal evidence. Idempotent identities require exactly equal content.
- Each canonical energy stream has one immutable origin and continuity key. Finalized intervals are contiguous/nonoverlapping across methods. Only source-processing paths can post known energy; generic append cannot bypass integration/counter validation or administrative recovery. Raw late events remain archived, while finalized energy is never automatically reconstructed or counted again. Method switches do not create a new origin.
- Integrate actual timestamped power with declared left hold<=45s. A direct instantaneous power reading yields **derived** kWh; a valid counter delta yields confirmed interval energy. Estimated power remains estimated, missing/expired/conflicting intervals remain unknown. A present reading cannot fill earlier hours. Counter reset/jump returns unknown rather than a negative/clipped delta. Stage estimates require independent duration/tolerance assumptions and never round ledger energy or command hardware.
- Dated tariffs must not overlap or mix currencies. Partial counter/recovered time allocation and estimated energy have estimated cost, distinct from known cost. Local-day splitting uses injected timezone and UTC elapsed time; counter subdivision cannot invent a measured distribution. Queued planner forecasts have an explicit energy period distinct from the temperature curve; unscoped legacy amounts remain unverified as budget references. Cycle budgets retain initial reference, known spend, unknown duration and projected overrun separately; lifetime origin is not mistaken for cycle spend.
- Recovery requires the explicit admin fake capability at the integration API, dry-run option, expected canonical total, exact current backup/head/hash, source evidence hash and unknown interval identities. Claims, request and kWh commit together; repeat is idempotent. Original unknown records are never overwritten. Partial-period allocation of aggregate recovery remains unknown; only complete covered scope can count its amount as known.
- Freeze initial/prestart before reference and choose original issue<=reference−12h with actual target coverage. Missing original freezes as missing. Preserve original curve/checksum/model/plan/source issue times **and planned energy**; latest is separate. Direct original/prestart writes cannot retroactively fill history. Actual comparison accepts exact reported direct temperature points, not estimated/recovered labels.
- History pages are indexed, capped256 rows, with cursor bound to query, immutable sequence watermark and archive-prefix hash. Readers pin a transaction snapshot. Summaries stream verified records with bounded memory; large archive work belongs to the explicit worker, never an HA event loop or safety path. Finalization bounds a raw batch to10000 points, which callers must split rather than truncate.

## Migration decisions and consequences

Synthetic `LegacyBundle` carries counters, hourly model, plan, one-shots, fan/night state and explicit fan policy, settings/state and frozen curves. Canonical source checksum and per-entry source/target schema, unit, checksum and continuity key form the manifest. `dry_run` does not write. Staging accepts an empty disposable target or an identical prior migration, atomically records all origins/state/evidence and returns a disarmed receipt. It does not load state into an actuator or auto-arm the runtime.

Rollback uses a consistent SQLite backup into another disposable directory, carries every post-freeze journal/energy event and consumed one-shot forward, reconstructs a typed legacy-shaped bundle with canonical totals, and remains STOP/disarmed/unreconciled. The original input and source DB are unchanged by rehearsal. This is neither a parser of actual private AppDaemon files nor a production/legacy rollback bridge.

Native HA config/options flow, actual authentication/API/async executor integration, target runtime/fsync behavior, physical topology/OEM protection, real backups/import, shadow and cutover are NOT_TESTED/NOT_AUTHORIZED here. G1/B01–B08 remain BLOCKED, B08 is unchanged, and WP2B is not started.

## Review correction decisions (PR16)

- An evidence hash is a content address of typed RecoveryProof, not an administrative attestation. Two separately archived independent/direct VALID KWH readings must support its amount, source and exact contiguous unknown interval. Proof and endpoints precede the current disposable backup; summary/budget also revalidate, so old unproven recovery blocks rather than becoming actual. The only numerical tolerance is 1e-9 kWh for subtraction; no time-profile allocation is inferred.
- Current author assertions and scalar freshness are distinct. A fresh admitted external assertion fences ownership durably even without state. Serialized author/action values never authenticate observed device state: all such assertions use unknown-owner feedback without an action. Ordered assertion freshness and source observation-clock rollback protection remain in the adapter; resumption requires the existing controlled procedure.
- Planner energy scope starts at forecast reference and ends at verified request horizon. Compute segment overlap using qualified synthetic request-stage power; never copy the whole-plan amount across a later reference. Missing scope/coverage/qualification produces None. Legacy unscoped evidence stays unavailable as a budget reference; original12h freezing is unchanged.
- These corrections do not add a transport, physical metrology/authentication, production migration or WP2B authorization. G1/B01–B08 remain BLOCKED.

## Original12h availability decision (repeat review6621066397)

An original12h candidate must satisfy curve.issued<=reference−43200 and candidate.recorded_at<=min(as_of,reference−43200). Source-issued lead cannot substitute for archived availability. Recheck both values in the immutable hashed payload after indexed selection. A late first invocation may use genuinely early archived evidence; an early-issued late receipt yields permanent MISSING. Original.recorded_at continues to mean freeze invocation, while the selected latest record preserves its receipt timestamp. Existing original records and generic latest/prestart/initial semantics remain unchanged; no historical rewrite or implicit legacy requalification occurs. Synthetic timestamps are injected trusted premises; real authenticated receipt/import remains blocked.
